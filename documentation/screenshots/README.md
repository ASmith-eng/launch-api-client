# Screenshots

Drop the captured PNGs here using these exact filenames so the links in the
top-level `README.md` resolve:

| File | What to capture |
|------|-----------------|
| `list-view.png` | The main list view — upcoming launches with status badges, countdowns, and the filter bar. |
| `detail-view.png` | A **crewed** mission detail view scrolled to show as many sections as possible (hero countdown, updates, crew, landing, vehicle specs, record bars). |
| `filter-panel.png` | The filter overlay open, showing the Status / Region / Crewed / Date categories. |

Tip: capture at a terminal size of at least 100 columns so the detail view
renders its two-column layout.
